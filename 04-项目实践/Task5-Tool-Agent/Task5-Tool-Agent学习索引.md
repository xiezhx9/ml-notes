# Task 5：Tool Agent 学习索引

> [!summary] 学习目标
> 能解释一次“模型决策 → 工具执行 → 观察反馈”的闭环，能判断 Agent 是否真正完成任务，并能用对照实验找到值得做的优化。

## 1. 四篇主笔记

| 阅读顺序 | 核心问题 |
|---|---|
| [[Task5-01-ReAct循环与消息协议]] | 模型怎样利用工具结果继续决策？消息、循环和终止如何配合？ |
| [[Task5-02-工具Schema路由与安全边界]] | 如何设计模型能正确使用、程序能可靠执行的工具？ |
| [[Task5-03-评测设计与实验复盘]] | 如何验收、计算指标、解释 S1–S4，并改进实验？ |
| [[Task5-04-现代Agent优化与工程实践]] | 怎样改进规划、上下文、恢复、并行和运行可靠性？ |

第一轮按顺序理解；之后按失败现象查阅对应专题。每篇末尾有自测和折叠答案。重点是能解释机制、诊断失败、设计对照，无需背模型 ID、逐轮耗时或测试题编号。

## 2. 与之前项目的联系

- [[Task3-05-S1-S5实验复盘]]：工具调用训练涉及格式与参数学习；Task5 把已有模型接到真实环境，观察多轮执行。
- [[Task4-02-FAISS检索与RAG评估]]：检索命中不保证答案正确；同样，工具调用成功不保证 Agent 完成任务。两者都需要分层评测。
