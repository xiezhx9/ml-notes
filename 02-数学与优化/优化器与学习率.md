# 优化器与学习率

## 1. 为什么需要优化器

神经网络训练的目标是最小化损失函数：

$$
\min_\theta L(\theta)
$$

其中：

- $\theta$：模型参数
- $L(\theta)$：损失函数
- $\nabla_\theta L$：损失函数对参数的梯度
- $\eta$：学习率

最基本的梯度下降更新公式是：

$$
\theta_{t+1}=\theta_t-\eta\nabla_\theta L(\theta_t)
$$

优化器的主要区别在于：如何利用当前梯度和历史梯度决定更新方向与步长。

## 2. SGD

### 公式

$$
\theta_{t+1}=\theta_t-\eta g_t
$$

其中：

$$
g_t=\nabla_\theta L(\theta_t)
$$

### 优点

- 算法简单，容易理解和实现。
- 额外状态少，内存占用低。
- 合理调参后通常具有较好的泛化能力。

### 缺点

- 对学习率比较敏感。
- 收敛速度可能较慢。
- 在狭长谷底中，容易在陡峭方向震荡，在平坦方向前进缓慢。

### PyTorch

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
)
```

## 3. SGD + Momentum

### 公式

先累积历史梯度：

$$
v_t=\beta v_{t-1}+g_t
$$

再更新参数：

$$
\theta_{t+1}=\theta_t-\eta v_t
$$

其中 $\beta$ 通常取 $0.9$。

### 直觉

可以把 $v_t$ 理解成一个带惯性的速度：

- 连续多个时刻方向相同：速度逐渐变大。
- 梯度方向来回变化：历史方向会抵消一部分震荡。

### 优点

- 减少普通 SGD 的震荡。
- 沿稳定方向加速前进。
- 通常仍然保留 SGD 较好的泛化特性。

### 缺点

- 多了动量超参数 $\beta$。
- 动量太大或学习率太大时，可能冲过最优点。

### PyTorch

```python
optimizer = torch.optim.SGD(
    model.parameters(),
    lr=0.01,
    momentum=0.9,
)
```

## 4. RMSprop

### 公式

维护梯度平方的滑动平均：

$$
s_t=\rho s_{t-1}+(1-\rho)g_t^2
$$

参数更新为：

$$
\theta_{t+1}
=\theta_t-\eta\frac{g_t}{\sqrt{s_t}+\epsilon}
$$

这里的平方、除法都是逐元素进行的。

### 直觉

- 某个方向梯度长期很大：$s_t$ 较大，该方向步长自动变小。
- 某个方向梯度较小：该方向相对使用更大的步长。

### 优点

- 可以为不同参数自动调整步长。
- 对梯度尺度差异较大的问题比较友好。
- 早期在 RNN 和非平稳目标中比较常见。

### 缺点

- 仍然需要调整学习率。
- 额外保存梯度平方的滑动平均，内存高于 SGD。
- 现代 Transformer/LLM 中通常不如 AdamW 常用。

### PyTorch

```python
optimizer = torch.optim.RMSprop(
    model.parameters(),
    lr=0.001,
)
```

## 5. Adam

Adam 同时结合 Momentum 和 RMSprop。

### 一阶矩：梯度的滑动平均

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t
$$

### 二阶矩：梯度平方的滑动平均

$$
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2
$$

### 偏置修正

由于 $m_0$ 和 $v_0$ 初始化为零，前几步的估计会偏小，因此需要修正：

$$
\hat m_t=\frac{m_t}{1-\beta_1^t}
$$

$$
\hat v_t=\frac{v_t}{1-\beta_2^t}
$$

### 参数更新

$$
\theta_{t+1}
=\theta_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}
$$

### 优点

- 同时利用动量和自适应学习率。
- 通常收敛较快。
- 对初始学习率相对不那么敏感。
- 适合快速实验和复杂模型。

### 缺点

- 需要保存一阶矩和二阶矩，额外内存约为参数量的两倍。
- 某些任务上最终泛化效果可能不如 SGD。
- 学习率和权重衰减的设置仍然很重要。

### PyTorch

```python
optimizer = torch.optim.Adam(
    model.parameters(),
    lr=1e-3,
)
```

## 6. AdamW

LLM 和 Transformer 中更常见的是 AdamW，而不是直接使用 Adam 加权重衰减。

```python
optimizer = torch.optim.AdamW(
    model.parameters(),
    lr=1e-4,
    weight_decay=0.01,
)
```

AdamW 将权重衰减与 Adam 的梯度更新解耦，通常比：

```python
torch.optim.Adam(
    model.parameters(),
    lr=1e-3,
    weight_decay=0.01,
)
```

更适合 Transformer 类模型。

## 7. 四种优化器对比

| 优化器 | 主要机制 | 优点 | 缺点 | 常见场景 |
|---|---|---|---|---|
| SGD | 当前梯度 | 简单、内存低、泛化较好 | 慢、对学习率敏感 | 传统 CNN、追求泛化 |
| SGD + Momentum | 梯度 + 历史方向 | 减少震荡、加速收敛 | 需要调动量 | CNN、稳定训练 |
| RMSprop | 梯度平方自适应缩放 | 不同方向使用不同步长 | 现代 LLM 中较少用 | RNN、非平稳问题 |
| Adam | Momentum + RMSprop | 收敛快、易用 | 内存较高、泛化未必最好 | 通用深度学习 |
| AdamW | Adam + 解耦权重衰减 | 适合 Transformer | 仍需调参 | LLM、Transformer |

## 8. 学习率怎么选

学习率没有适用于所有任务的固定值。它取决于：

- 输入和参数的尺度。
- 损失函数的曲率。
- batch size。
- 模型规模。
- 是否使用学习率调度器。

### 常用起点

| 优化器 | 建议起始范围 |
|---|---:|
| SGD | $0.01$ 或 $0.1$ |
| SGD + Momentum | $0.01$ 或 $0.1$ |
| RMSprop | $10^{-3}$ 或 $10^{-2}$ |
| Adam | $10^{-3}$ |
| AdamW | $10^{-4}$ 或 $10^{-3}$ |

这些只是起始值，不是最终最优值。

### LLM 微调

微调预训练模型时通常使用更小的学习率：

```text
AdamW：1e-5 ~ 5e-4
```

可以从以下值开始尝试：

```python
lr = 1e-5
# 或
lr = 2e-5
```

## 9. 当前二次函数实验

实验函数：

$$
f(x_1,x_2)=0.2x_1^2+2x_2^2
$$

梯度为：

$$
\nabla f=(0.4x_1,4x_2)
$$

Hessian 矩阵为：

$$
H=
\begin{bmatrix}
0.4&0\\
0&4
\end{bmatrix}
$$

$x_2$ 方向的曲率更大，所以它是一个狭长的二次谷底。

对于普通梯度下降，稳定条件近似为：

$$
0<\eta<\frac{2}{\lambda_{\max}(H)}
$$

这里：

$$
\lambda_{\max}(H)=4
$$

因此：

$$
0<\eta<0.5
$$

实验中使用：

```python
x_init = torch.tensor([3.3, -1.2])
lr = 0.01
```

对四种优化器先统一使用 `0.01`，方便公平观察优化轨迹：

```python
torch.optim.SGD([x], lr=0.01)

torch.optim.SGD(
    [x],
    lr=0.01,
    momentum=0.9,
)

torch.optim.RMSprop([x], lr=0.01)

torch.optim.Adam([x], lr=0.01)
```

但要注意：

> Adam 的 `lr=0.01` 和 SGD 的 `lr=0.01` 并不代表相同的实际参数步长。

Adam 会根据梯度的一阶、二阶统计量自动缩放更新量。

## 10. 公平比较与实际调参

如果目的是观察算法机制：

1. 让所有优化器从同一个初点开始。
2. 先使用相同学习率，例如 `0.01`。
3. 记录参数轨迹和损失曲线。
4. 观察震荡、收敛速度和最终损失。

如果目的是获得最好结果：

1. 为每种优化器分别搜索学习率。
2. 使用验证集比较效果。
3. 配合学习率调度器。
4. 同时关注训练损失和验证损失，避免只追求训练集下降。

## 11. 经验记忆

```text
SGD：只看当前梯度
Momentum：当前梯度 + 历史方向
RMSprop：根据梯度大小调整每个参数的步长
Adam：Momentum + RMSprop
AdamW：更适合 Transformer/LLM 的 Adam 变体
```

一个实用选择顺序：

```text
快速实验：Adam
Transformer/LLM：AdamW
追求泛化：SGD + Momentum
梯度尺度差异明显或 RNN：RMSprop
```

## 12. 初始化标准差的作用

初始化时，权重通常从均值为 0 的随机分布中采样：

$$
W\sim\mathcal N(0,\sigma^2)
$$

这里的标准差 $\sigma$ 决定权重分布的整体尺度。它不是说每个权重都等于 $\sigma$，而是说权重通常会在 $\sigma$ 附近波动。

如果：

$$
z=Wx
$$

输入标准差为 $s_x$，权重标准差为 $s_w$，输入维度为 `fan_in`，在独立性和均值接近 0 的近似下：

$$
\mathrm{std}(z)
\approx
\sqrt{\text{fan\_in}}\,s_w\,s_x
$$

因此，权重标准差会影响每层激活值的标准差，进而影响梯度大小。

### 过大或过小的影响

```text
权重 std 太小 -> 激活值逐层变小 -> 梯度消失
权重 std 太大 -> 激活值逐层变大 -> 梯度爆炸

为什么标准差会影响数据本身，因为正态分布的标准差就是数据值波动的上下限
所以标准差不仅影响数据的波动，还会影响数据值本身的大小

合理初始化   -> 信号和梯度保持在合理尺度
```

初始化的目标不是让权重标准差等于 1，而是让激活值和梯度在深层传播时大致保持稳定，通常处于数量级 1 附近。

## 13. Kaiming 初始化的标准差

对于 ReLU 网络，Kaiming 初始化使用：

$$
s_w=\sqrt{\frac{2}{\text{fan\_in}}}
$$

代入激活值标准差公式：

$$
\mathrm{std}(z)
\approx
\sqrt{\text{fan\_in}}
\sqrt{\frac{2}{\text{fan\_in}}}
 s_x
=\sqrt2\,s_x
$$

注意：结果必须乘上当前输入的标准差 $s_x$。只有当 $s_x\approx1$ 时，线性层输出标准差才约为 $1.414$。

例如 `fan_in=512`：

$$
s_w=\sqrt{\frac{2}{512}}\approx0.0625
$$

如果当前输入标准差为 $1$：

$$
\mathrm{std}(z)\approx\sqrt2\approx1.414
$$

下一层的输入已经是经过 ReLU 的激活值，标准差通常不再等于 1，因此不能每一层都直接套用 $s_x=1$。

## 14. ReLU 对标准差的影响

ReLU 会把负数变为 0：

$$
\mathrm{ReLU}(z)=\max(0,z)
$$

如果 $z$ 近似服从零均值正态分布，则经过 ReLU 后会丢失一部分信号。对中心化标准差而言，可以近似写成：

$$
\mathrm{std}(\mathrm{ReLU}(z))
\approx
0.584\mathrm{std}(z)
$$

因此，当 Kaiming 使线性层输出满足：

$$
\mathrm{std}(z)\approx\sqrt2s_x
$$

ReLU 后大致为：

$$
\mathrm{std}(\mathrm{ReLU}(z))
\approx0.826s_x
$$

Kaiming 主要保持的是前向信号的整体尺度或二阶矩，并不保证每层的中心化标准差严格等于 1。

## 15. 初始化是否会一直保持标准差

不会。初始化只决定训练开始时的权重分布：

$$
W_0\sim\mathcal N(0,\sigma^2)
$$

训练时优化器会不断更新权重：

$$
W_{t+1}=W_t-\eta\nabla_W L
$$

因此训练后可能发生：

- 权重均值改变；
- 权重标准差改变；
- 不同权重之间产生相关性；
- 激活值标准差发生漂移。

所以一般不能保证：

$$
\mathrm{std}(W_t)=\mathrm{std}(W_0)
$$

初始化更像是给网络一个合理的起跑状态，而不是整个训练过程中的标准差约束。

训练稳定性还依赖：

- 学习率；
- 优化器；
- 权重衰减；
- BatchNorm 或 LayerNorm；
- 残差连接；
- 梯度裁剪。

可以用下面的代码观察训练后各层权重标准差：

```python
for name, param in model.named_parameters():
    if param.ndim >= 2:
        print(
            name,
            "mean =", param.mean().item(),
            "std =", param.std().item(),
        )
```
